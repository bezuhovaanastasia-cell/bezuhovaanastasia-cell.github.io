Samurai helps its owner prepare artwork, arrange music, render a video and publish it to the Samurai LoFi YouTube channel.

This website describes the personal application named Samurai that appears on Google's authorization screen. It is an information page, not a login portal or a public video-generation service.

How Samurai works

  1. The owner chooses a creative idea, artwork and music through a private Telegram conversation.
  2. The assistant renders the selected assets into a video on the owner's server.
  3. When the owner requests publication, Samurai uploads the video, its title, description and thumbnail to the connected YouTube channel.
  4. The assistant checks YouTube's processing status and returns the resulting video link to the owner.
A personal connection. YouTube access is used for the owner's channel. Public visitors cannot connect accounts, issue commands or access the owner's media through this website.

Why Google access is requested

Samurai requests permission to upload YouTube videos and read the connected YouTube account. These permissions let it confirm the correct channel, upload approved material, set a thumbnail and check processing and visibility. Google authorization is handled by Google; this website never asks for a Google password.

For help or to request removal of the application's stored data, the owner can use the existing private Samurai Telegram conversation or contact the application operator through the Samurai website repository.
