Samurai application

Privacy policy

Effective date: 9 October 2026

Samurai is an owner-operated personal assistant used to prepare and publish music videos. This policy covers the application and this public information website.

Google and YouTube data accessed

With the owner's explicit Google authorization, Samurai receives OAuth access and refresh tokens. It uses the YouTube Data API to read the connected channel's identity and the metadata, processing status and visibility of videos handled by the application. It uploads owner-approved video files, titles, descriptions, tags, audience and visibility settings, and thumbnails.

The requested scopes are youtube.upload and youtube.readonly. Samurai does not request access to Gmail, Google Drive, contacts or payment information.

How data is used

Google and YouTube data is used to identify the intended channel, carry out the owner's publishing instructions, resume interrupted transfers, verify the result and report the video link or an error to the owner. The application does not sell Google user data, use it for advertising or use it to develop or train generalized AI or machine-learning models.

Storage and protection

Authorization tokens are stored in access-restricted files on the owner's Hetzner server. They are not published on this website or in its GitHub repository. Upload progress, video identifiers, links and task metadata are retained on the server to support recovery and avoid duplicate uploads. Access to the Telegram assistant is restricted to the owner's approved account.

Services involved and sharing

Google and YouTube receive authorization requests and uploaded video material. Hetzner hosts the private application and its files. Telegram carries the owner's commands and the assistant's responses, including result links. Configured AI and music services may process creative prompts and selected artwork or music as part of the owner's requested workflow; YouTube authorization tokens are not shared with those services. GitHub hosts only this public information website and may process ordinary web request data under its own privacy statement.

Data is not disclosed to other parties except as required to provide the requested workflow, comply with applicable law or protect the application against abuse. Samurai's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

The owner controls the source artwork, music and publication records retained on the server. For new episodes configured for cleanup, Samurai removes its temporary transport video only after YouTube processing and the requested visibility have been verified. Source artwork, music, descriptions and result links are retained for reuse and recovery until the owner requests deletion. Legacy files and any separately requested backups are preserved.

The owner can request deletion of stored authorization tokens and application data through the existing private Samurai Telegram conversation or the Samurai website repository. Deleting a server copy does not delete a video already stored on YouTube. YouTube videos are managed separately through the owner's YouTube account.

Revoke access

The owner can revoke Samurai's Google access at any time through Google Account connections. Revocation prevents future authorized API activity once the credentials are no longer valid. To remove locally retained records and tokens as well, request deletion from the application operator.

This website

This is a static information website. It has no account registration, forms, application database, advertising or analytics scripts added by Samurai. It does not expose the assistant, its credentials or its private media library. GitHub's hosting infrastructure may maintain standard access logs; see the GitHub Privacy Statement.

Changes and contact

This page will be updated if the application's data practices change. For questions, the owner can contact the operator through the private Samurai Telegram conversation or the Samurai website repository.
